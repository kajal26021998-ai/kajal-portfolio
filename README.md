# Kajal Sharma, portfolio

Personal portfolio for Kajal Sharma, Head of Content (Healthcare & Wellness).

Built with Vite, React, TypeScript, Tailwind CSS v4, GSAP and Motion.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # outputs to dist/
```

## Deploy on Vercel

Import the repository in Vercel. It detects Vite automatically:
build command `npm run build`, output directory `dist`.

## Editing content

- Site text: `src/content.ts`
- Work and gallery: `src/work.ts`, images in `public/work/`
- Resume download: `public/Kajal-Sharma-Resume.pdf`
